# 数据处理说明 · vertciti chat

这份说明描述代码实际做了什么（以 `e8f9566` 之后的 remediation 分支为准）。它不是法律文本；
面向公众发布前，隐私政策与服务条款需由法务确认（尚未完成）。

## 存什么

| 数据 | 存放 | 保留 | 谁能看 |
|---|---|---|---|
| 对话内容（你的消息与回复） | SQLite `messages` | `CHAT_RETENTION_DAYS`（默认 30 天）后自动删除；可随时在页面"删除本对话" | 只有创建它的访客令牌（或服务 key）；运营方可直接读数据库 |
| 会话标题与时间 | `sessions` | 同上 | 同上 |
| 产品事件（建会话、发消息、CTA 点击） | `events` | 同上；随会话删除 | 运营方（admin 指标） |
| 访客 id | 令牌内，事件 `subject` | 令牌 7 天过期；事件随会话删除 | 运营方 |
| 客户端 IP | **不存原文**；只存以服务端密钥（`CHAT_VISITOR_SECRET`）做 HMAC 后的 24 位摘要，用于限额 | 用量计数 35 天 | 运营方（没有密钥无法还原；持有密钥者理论上可枚举 IPv4 地址空间反查，密钥须按 RUNBOOK 保管） |
| 每日用量计数 | `usage_daily` | 35 天 | 运营方 |
| 审计记录（急停、删除、越权尝试） | `audit_log`（哈希链） | 永久（只追加），**不含对话内容** | 运营方 |
| memory 记录（服务调用方写入） | `memory_records` | 调用方设定的 TTL | 仅本模块；`pii_fields` 与 `{"pii":true}` 标记的字段在落库前替换为 `[REDACTED]` |

浏览器本地（localStorage）只存两样：访客令牌 `vc_visitor`（用于找回自己的历史对话）和语言选择 `vc_lang`。
没有第三方脚本、统计或广告。

## 发给谁

- 你的消息与最近若干轮历史（`CHAT_HISTORY_MAX_CHARS` 以内）通过 HTTP 发给 vertciti 的 anomalies 智能体运行时，
  它可能再调用大模型供应商。供应商与其数据政策由部署方配置，本仓库无法替其承诺。
- 日志只记录方法、路径、状态码、耗时与 trace id；不记录请求体、查询串、请求头或 key。

## 删除

- 页面"删除本对话"（点两次）→ `DELETE /v1/chat/sessions/{id}`：删除该会话的消息、事件和会话行，审计里只记一条"已删除 N 条"。
- 急停期间删除仍然可用。
- 备份中的副本按备份保留期（默认 14 份）自然过期；需要从备份中也删除时，按 RUNBOOK 处理。

## 尚未覆盖（如实）

- 未做 PIPL / GDPR 合规评估；没有数据处理协议模板；没有面向用户的"导出我的数据"。
- 运营方（有数据库访问权的人）可以读取保留期内的对话内容；尚无静态加密。
