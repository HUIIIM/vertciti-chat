# vertciti 智能助手（chat）— 产品一页纸

> 状态：early（dev，未上公网）· 版本：0.2.0（未发布）· 更新：2026-10-28
> 所属：[vertciti](https://vertciti.com) — 一家公司，一个人生。

## 一句话
访客在 vertciti 工作台里免费、免注册地提问，智能体直接回答；运营方看得到每条回复花了多少钱、带来多少线索，并能两步急停。

## 解决什么问题
- 痛点：想试 vertciti 智能体的人，在注册和付费墙前就流失了；运营方又怕免费入口被刷爆、花费失控、出事停不下来。
- 现在的替代做法：通用聊天产品（需要账号）或自建聊天页（通常没有额度、急停、审计和成本口径）。

## 给谁
- 首要用户：第一次接触 vertciti 的访客；运营方（值班的人）。
- 不是给谁：需要长期账号、团队协作、文件知识库的用户（不在本模块范围）。

## 怎么用（三步）
1. 打开页面，直接输入问题（无需 key、无需注册；页面自动领取匿名访客令牌）。
2. 看流式回复；随时"停止"；需要时从"历史对话"回到之前的对话，或"删除本对话"。
3. 点能力菜单去主站了解付费能力（带 UTM，计入单线索成本）。

## 为什么是我们（差异化）
| 维度 | 我们 | 常见替代 |
|---|---|---|
| 诚实标签 | 每个响应带 `honesty`；`/health` 分组件标注；不可用时不编造回复 | 通常没有 |
| 运营安全 | 两步急停、哈希链审计 + 每日外部锚定脚本、按访客/IP 的额度 | 自建页面通常没有 |
| 成本口径 | 每条回复整数分成本、会话成本、单线索成本（无线索时为 null） | 只有 token 计量 |

## 证据
- 测试：112 个 pytest（含每条路由的越权回归）、7 个前端单测、33 项浏览器端到端检查；需求追溯矩阵见 [assurance/traceability.md](assurance/traceability.md)。
- 恢复演练：[ops/restore-drills.md](ops/restore-drills.md)。
- 不能证明的：未接真实运行时与真实大模型的负载表现；未上公网，无真实用户数据。

## 边界与风险
- 不做：代码执行、文件上传、账号体系（见 ROADMAP"明确不建"）。
- 已知限制：单进程单实例；异地备份与审计锚定的外部存储需运营方提供；隐私政策未经法务确认。
- 安全与隐私：见 [PRIVACY.md](PRIVACY.md)；对话默认 30 天删除，可随时删除。

## 与其他 vertciti 产品的组合
- 与 anomalies 运行时：只经 HTTP 调用（M1 零依赖），运行时负责"想"，本模块负责"守门、计费、记账、展示"。

## 衡量指标
- 北极星：单线索成本（`cost_per_lead_cents`）。
- 护栏：回复成功率 ≥ 98%、可用性 ≥ 99.5%（[SLO.md](SLO.md)）、每日花费不超预算。
